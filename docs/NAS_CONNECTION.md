# SampleGlideでNASのサンプルを使う

## SMB接続済みのNASを使う方法

2026年9月9日に、SMBで接続済みのNAS共有フォルダを使う操作を実機で確認しました。以下の共有名 `SampleLibrary` とパスは説明用の例です。利用するNASの共有名とマウント先に読み替えてください。

1. SampleGlideを開き、**「フォルダを追加」** を選びます。
2. フォルダ選択画面で、接続済みの共有フォルダにある素材フォルダを選びます。パスを直接指定する場合は **⌘⇧G** で `/Volumes/SampleLibrary/Samples` などを開きます。
3. 追加したフォルダを選び、カラム内のフォルダをクリックして右の階層へ進みます。**↑↓で項目を選択、→で選択フォルダに入り、←で親フォルダへ戻れます。** 空フォルダや読み込み中でも←で戻れます。階層を移動すると検索の絞り込みを解除します。
4. 音声ファイルをクリック、または上下キーで選ぶと、原音の試聴が始まり、下のプレビューに波形を表示します。自動試聴は下部のスイッチ、または「試聴設定」（⌘,）でオフにでき、設定はこのMacに保存されます。NASの転送速度と音声の長さに応じて、波形の生成には時間がかかる場合があります。

上記接続確認時には、共有フォルダ直下の複数の素材フォルダを確認しました。実NAS全件の索引作成完了は未検証です。普段使う素材フォルダを複数追加するか、共有フォルダ全体を参照・検索したい場合は `/Volumes/SampleLibrary` のような共有フォルダのマウント先を追加してください。

この使い方では、Finderで接続済みのフォルダを直接読み込みます。**アプリのAPI URL・ライブラリID・APIトークンの設定は不要**です。SMBの接続認証はmacOSが管理します。

## 全階層から検索する

1. フォルダ画面の検索欄へ名前を入力します。検索範囲は初期設定で **「すべての場所」** になり、登録したMac／NASの素材フォルダを階層横断で検索します。サイドバーの **「全体検索」** からも開けます。
2. 名前・パス・メモ・タグで絞り込みます。空白区切りの言葉はすべてに一致する素材が対象で、`#drums #loop` は両方のタグ条件で検索します。
3. 結果のファイルをクリック・↑↓で選ぶと、その一覧のまま波形を表示します。自動試聴ONなら再生し、OFFなら選択のみです。フォルダはクリックで選択し、ダブルクリック・Return・→で開きます。
4. 結果は200件ずつ表示し、続きは「さらに読み込む」で追加します。右クリックからお気に入り登録やメモ・タグの編集もできます。

アプリは起動時に登録した場所のディレクトリと対応音声をバックグラウンドで読み込み、このMacの `~/Library/Application Support/jp.samplebrowser/library-index.sqlite3` に検索用の索引を保存します。初回は読み込めた範囲だけが検索対象となり、大きなNASでは時間がかかります。索引作成中もカラムでのフォルダ参照・試聴は使えます。

検索画面にプログレスバー、処理済み・待機中のフォルダ数と「一時停止」「再開」「全体を更新」を表示します。初回走査では読み込みながら対象を発見するため、全体数が未確定の間は動くバーを表示し、パーセントは表示しません。処理件数も再起動後に引き継ぎます。途中でアプリを終了しても残りの階層から再開し、一時停止の設定は次の起動にも引き継ぎます。正常完了後に自動で新しい全件走査を始めることはありません。NASが外れても保存済みの検索結果は残りますが、音声の再生やフォルダを開くには再接続が必要です。追加・削除・変更を反映する場合、再接続後に「全体を更新」を使ってください。この操作は登録した場所を先頭から再走査します。

一時的なフォルダ読み取り失敗は、2秒後・10秒後を目安に最大2回、自動で再試行します。その間も読めるフォルダの処理を進めます。再試行待ちの状態も保存されるため、一時停止や再起動で最初から走査し直す必要はありません。3回とも失敗したフォルダはパス付きのエラーとして表示し、以前の検索データを残して次回の走査で再確認します。

検索範囲を **「このフォルダ」** に切り替えると、右端カラム内だけの名前・メモ・タグ絞り込みになります。全体検索の索引は音声をコピーせず、BPM・キーなどの音声解析も行いません。下記の任意のサーバー共有索引とは別の、Mac内の検索機能です。

## お気に入り

- 左側の「お気に入りフォルダ」の＋、またはお気に入り画面の「新規フォルダ」で、整理用フォルダを追加できます。
- フォルダ名は左側のフォルダを右クリック→「フォルダ名を変更」、または画面右上の鉛筆ボタンから変更できます。
- 音声／フォルダを右クリック→「お気に入りフォルダ」で登録先を選びます。同じ素材を複数のフォルダに登録できます。
- 既存のお気に入りは標準の「お気に入り」フォルダに引き継ぎます。整理用フォルダを削除しても、中の素材は「すべてのお気に入り」に残ります。
- カラム内のフォルダまたは音声ファイルを右クリックして、お気に入りに登録できます。
- 音声ファイルのお気に入りをクリックすると、一覧に留まったまま試聴します。これは再生操作なので、自動試聴がOFFでも再生できます。
- フォルダのお気に入りは、そのフォルダを開きます。ファイルの場所へ移動したいときは、右クリックの「フォルダで表示」を使います。
- お気に入りの名前を変更できます。変更されるのはアプリ内の表示名で、NAS上のファイル名・フォルダ名は変更しません。
- 直接フォルダを参照するモードの登録情報とお気に入りは、このMacに保存します。

## メモ・タグと検索

1. カラム表示やお気に入りで、ファイル／フォルダを右クリック → **「メモとタグを編集…」**。選択後、画面上部の **「メモ・タグ」** からも開けます。
2. メモとタグを入力して保存します。タグは複数登録でき、既存タグの候補からも選べます。
3. 左側の **「メモ・タグ検索」** で、メモ・タグを保存した素材をフォルダ横断で検索できます。タグのボタンを押して絞り込むか、検索欄へタグ名・メモの言葉を入力します。`#drums #loop` のような複数条件はすべてに一致する素材を表示します。
4. 全体検索とお気に入りの検索欄でも、名前に加えてメモ・タグを検索できます。「メモ・タグ検索」は注釈を保存した素材だけが対象です。注釈のない素材も含めて探すには「全体検索」を使用してください。

「メモ・タグ検索」では、音声の結果をクリックすると一覧のまま試聴し、フォルダはクリックでその場所を開きます。登録情報はこのMacの `~/Library/Application Support/jp.samplebrowser/annotations.json` に保存され、全体検索にも反映します。NAS上の原音へ書き込まず、APIの接続設定も不要です。

## NASが外れた場合

Finderの「場所」→「ネットワーク」でNASを開き、利用する共有フォルダに再接続します。アドレスを使う場合は、Finderの「移動」→「サーバへ接続」で `smb://NASのIPアドレス/共有名` を指定し、求められた場合にNASのユーザ名とパスワードを入力します。手順とSMBアドレス形式は [Appleの接続手順](https://support.apple.com/ja-jp/guide/mac-help/mchlp1140/mac)・[対応するアドレス形式](https://support.apple.com/ja-jp/guide/mac-help/mchlp3015/mac) を参照してください。

再接続後、SampleGlideで対象フォルダを開き直します。macOSのマウント先が `/Volumes/SampleLibrary-1` など別の名前になった場合は、新しい接続先を「フォルダを追加」で選び直してください。

## 任意の共有索引について

この公開版にはNASサーバー・DB・配置設定を含めていません。アプリに残る「共有索引」は、互換APIを別途用意した場合の機能です。上記のSMB接続によるフォルダ参照・検索・試聴には不要です。

## DAWへ追加する

未加工のサンプルは、下部の「DAW へドラッグ」から原音を直接渡せます。WAV生成ボタンを押す必要はありません。範囲・テンポ・移調を変更した音声は自動で準備され、完了するとドラッグできます。DAWが原音の場所を参照する方式ではNAS接続が必要なため、プロジェクトに音声を取り込んで保存する場合はDAWの素材収集機能を利用してください。
