**欲しい音を、すぐ制作へ。**

SampleGlideは、Mac内やNAS上のサウンドサンプルを探し、試聴・整理してDAWへ渡すネイティブmacOSアプリです。Finder風のカラム表示で階層をたどるほか、登録した素材フォルダ全体を名前・メモ・タグで検索できます。選択した音をすぐ試聴し、お気に入りフォルダで自分のライブラリを整理できます。

Finderに接続済みのNASは、素材フォルダを追加するだけで使えます。この公開リポジトリにはmacOSアプリのソースを収録しています。Rust製NASサーバー、DBマイグレーション、外部設計資料、API仕様は含めていません。

[GitHubリポジトリ](https://github.com/bassmicrobe/sampleglide-public) · [NAS接続ガイド](docs/NAS_CONNECTION.md) · [macOS技術資料](apps/macos/README.md)

**開発版：2026年10月15日時点のソースを公開しています。** すべての機能・動作環境を検証済みという意味ではありません。未対応・未検証の項目は[現在の制限](#limitations)に記載しています。

## ビルドして起動する

フォルダ表示・全体検索・試聴は、アプリ単体で利用できます。

| 必要環境 | 条件 |
|---|---|
| macOS | 14以降 |
| ビルドツール | Swift 5.10以降を含むXcode／Command Line Tools |
| ソース取得 | Git |

Apple Silicon / macOS 26 / Swift 6.3.3で検証しています。IntelとmacOS 14での実機試験は未実施です。

```sh
git clone https://github.com/bassmicrobe/sampleglide-public.git
cd sampleglide-public
bash apps/macos/scripts/build-app.sh
open 'apps/macos/dist/SampleGlide.app'
```

取得済みのリポジトリでは、そのルートでビルド部分から実行してください。生成先は `apps/macos/dist/SampleGlide.app` です。`/Applications` への自動インストールは行いません。現時点ではアドホック署名で、配布用の署名・公証は未対応です。

開発中はSwiftPMからも起動できます。

```sh
swift run --package-path apps/macos SampleGlide
```

## 素材フォルダを使い始める

1. NASを使う場合は、Finderで共有フォルダへ接続します。接続済みなら次へ進めます。
2. SampleGlideの **「フォルダを追加」** で、Mac内またはNASの素材フォルダを選びます。
3. 左側の「場所」から階層をたどるか、検索欄・「全体検索」から登録したすべての場所を検索します。初回はバックグラウンドで読み込めた素材から検索できます。
4. 音声を選んで試聴し、右クリックからお気に入り・メモ・タグを追加します。
5. 下部の **「DAW へドラッグ」** から素材を渡します。

この使い方ではAPI URL・ライブラリID・APIトークンの設定は不要です。SMBの認証はmacOSが管理します。NASのマウント先は環境や再接続によって変わる場合があるため、接続・再接続の手順は[NAS接続ガイド](docs/NAS_CONNECTION.md)を参照してください。

## 主な機能

### フォルダ・サンプルを探す

- Mac内やマウント済みNASの素材フォルダを複数登録し、「場所」から切り替え。
- Finder風のカラム表示で複数階層を移動。カラムは表示する階層を読み込むため、全体検索の索引作成完了を待たずに利用できます。
- フォルダ内のWAV／AIFF／FLACを表示。実際に再生できる符号化方式はmacOSのCore Audioに依存。
- フォルダ画面の検索範囲は初期設定で「すべての場所」。「このフォルダ」に切り替えると、右端カラムだけを名前・メモ・タグで絞り込みます。カラムの階層を左右キーで移動すると絞り込みを解除します。
- 接続切れや読み込み失敗を表示し、カラムから再読み込み。

### 登録した場所をまとめて検索する

- サイドバーの **「全体検索」**、またはフォルダ画面の「すべての場所」から、登録した場所の全階層を検索。
- 起動時に各場所のディレクトリと対応音声をバックグラウンドで読み込み、このMacのSQLiteへ名前・パスなどの索引を保存。終了・中断後も残りの階層から再開します。
- 名前・パス・保存したメモ・タグを部分一致で検索。空白区切りの条件はAND、`#drums #loop` は両方のタグ条件に一致する素材を表示します。
- 初回の索引作成中も、読み込み済みの素材から結果を表示。200件ずつ「さらに読み込む」で追加表示します。
- ファイルをクリック・↑↓で選ぶと一覧のまま波形表示・試聴。自動試聴のON／OFF設定に従います。索引更新だけで同じ素材を再生し直しません。
- フォルダはクリックで選択し、ダブルクリック・Return・→でその場所を開きます。右クリックからメモ・タグ、お気に入り、フォルダやFinderでの表示も操作できます。
- 走査中は動くプログレスバーと、処理済み・待機中のフォルダ数を表示。全体数が未確定の間は割合を表示しません。一時停止・再開に対応し、再起動後は未完了の続きだけを処理します。走査が終わったらバーを消し、一部取得できなかった場所がある場合はその内容を表示します。正常完了後は自動で全件走査を繰り返しません。「全体を更新」を押した時だけ、変更確認のため先頭から再走査します。
- フォルダの読み取りに失敗すると、2秒後・10秒後を目安に最大2回再試行します。待機中も他のフォルダを処理し、再試行の状態はアプリ再起動後も引き継ぎます。繰り返し失敗した場合は対象パスを表示し、以前の検索データを保持します。
- NASが切断されても保存済みの検索結果は保持。再生・フォルダを開く操作には元の場所への接続が必要です。再接続後は「全体を更新」で反映できます。

この索引はファイル名などを検索するためのものです。音声内容のコピーやBPM・キー解析は行いません。初回の結果は読み込み済みの範囲に限られ、大きなNASでは全体を検索できるまで時間がかかります。

### 選択して試聴・波形を編集する

- ファイルをクリック、またはカラム内の↑↓キーで選ぶと自動試聴。原音の再生は波形全体の解析完了を待たずに開始します。
- 選択した素材の波形を自動読み込み。長い素材やNASの転送状況によって、表示まで時間がかかる場合があります。
- 自動試聴は初期設定でON。下部のスイッチ、または「試聴設定」（⌘,）でON／OFFを変更し、このMacに保存。
- 波形をクリックすると、その位置から再生。クリックだけでは切り出し範囲の開始・終了位置を変更しません。自動試聴OFFでも操作できます。
- 波形の開始・終了ハンドルをドラッグ、またはフレーム数を入力して切り出し範囲を指定。
- 元BPM・目標BPMの手入力によるテンポ変更（0.25〜4倍）、半音単位の移調（±24半音）、試聴音量・ループ再生。
- テンポ・移調を適用した試聴と書き出しは同じ処理を使用。加工した試聴は音声の準備完了後に再生します。

### お気に入りを整理する

- ファイル／ディレクトリを右クリックして追加・登録解除。お気に入りの表示名を変えても、元のファイル名・ディレクトリ名は変わりません。
- 「お気に入りフォルダ」の＋、または「新規フォルダ」で整理用フォルダを複数作成。名前は右クリックの「フォルダ名を変更」や鉛筆ボタンから変更できます。
- 右クリックの「お気に入りフォルダ」で登録先を選択。同じ素材を複数フォルダへ登録でき、整理用フォルダの削除・所属解除後も「すべてのお気に入り」に残ります。
- ファイルのお気に入りは、一覧に留まったまま波形を表示して試聴。明示的な再生操作なので、自動試聴OFFでも再生します。
- フォルダのお気に入りはその場所を開きます。ファイルの場所を開くには右クリックの「フォルダで表示」を使用します。
- 登録した場所・お気に入り・表示名・整理用フォルダは再起動後も保持します。

### メモ・タグを付けて検索する

- ファイル／ディレクトリを右クリック →「メモとタグを編集…」、または上部の「メモ・タグ」から編集。
- 日本語・複数行のメモ、複数タグの追加・削除、既存タグ候補からの選択。タグはカンマ・改行でまとめて追加できます。
- 同じ素材のメモ・タグは、カラム表示・お気に入り・専用検索で共通。お気に入りの表示名を変更しても保持します。
- **「メモ・タグ検索」** は、メモ・タグを保存した素材だけをフォルダ横断で検索する専用画面です。注釈のない素材も探す場合は「全体検索」を使います。
- この専用画面の通常の検索語は名前・メモ・タグを対象にし、空白区切りの語をAND条件で検索。`#drums #loop` は両方のタグ条件に一致する素材を表示します。
- `#タグ` はタグの部分一致、タグボタンは完全一致で絞り込み。
- 「メモ・タグ検索」のファイルはクリックで一覧のまま試聴し、フォルダはクリックでその場所へ移動。
- お気に入り・メモ・タグ検索でも↑↓で選択できます。キー選択の試聴は自動試聴ON／OFFに従い、クリック・Returnでは明示的に試聴／フォルダを開きます。

### DAWへ渡す

- **未加工・全範囲のサンプルは原音を直接ドラッグ。WAV生成や変換の操作は不要です。**
- 原音の確認が終われば、波形の読み込み中でもドラッグできます。切り出し・BPM・移調の編集は、波形の準備が終わってから使えます。
- 切り出し範囲・テンポ・移調を変更した場合は、加工WAVを自動で準備。完了すると「編集した音声を DAW へドラッグ」から渡せます。
- 加工WAVは `~/Music/Sample Browser Exports/` に保存。明示的なWAV書き出しも可能です。
- 波形クリックによる試聴位置の変更は、DAWへ渡す範囲に影響しません。
- 原音は上書きせず、生成した書き出しファイルは自動削除しません。DAWがNAS上の原音を参照する場合はNAS接続が必要です。プロジェクト内に保持する場合はDAWの素材収集・コピー機能を利用してください。

### 画面・デザイン

ダークグレーにラベンダー・シアンを合わせた日本語UIです。大きめのフォント・一覧行・ボタンを使い、サイドバー・ブラウザ・素材詳細・波形プレビューを配置しています。狭いウィンドウでは素材詳細をシートで表示します。

提供されたフォルダと波形のロゴを、アプリアイコンと画面左上の文字入りロゴに使用しています。画像はアプリに同梱し、READMEではライト／ダーク表示に合わせてロゴを切り替えます。

## 主な操作

| 操作 | 動作 |
|---|---|
| ↑ / ↓ | カラム／全体検索で項目を選択。音声は自動試聴ONなら再生 |
| → | カラムでは選択したフォルダへ入り、読み込み後に項目を選択。全体検索では選択フォルダを開く |
| ← | カラムで子階層を閉じ、親フォルダへ戻って試聴を停止 |
| Return / ダブルクリック | 全体検索で選択したフォルダを開く |
| Space | 試聴の再生・停止 |
| ⌘O | ローカル音声ファイルを開く |
| ⌘F | 検索欄へフォーカス |
| ⌘, | 試聴設定を開く |
| ⌘S | メモ・タグ編集画面で保存 |
| 波形をクリック | その位置から試聴。切り出し範囲は維持 |
| 波形の開始・終了ハンドルをドラッグ | 切り出し範囲を変更 |
| ファイル／フォルダを右クリック | お気に入り・メモ・タグなどの操作 |

空フォルダや読み込み中のカラムからも←で戻れます。登録した「場所」より上の階層へは移動しません。テキスト入力中の矢印キーやSpaceは通常の入力操作になります。

## データの保存先

| データ | 保存先・範囲 |
|---|---|
| 登録した場所、お気に入り、表示名、お気に入りフォルダ | このMacの `~/Library/Application Support/jp.samplebrowser/folders.json` |
| ファイル／ディレクトリのメモ・タグ | このMacの `~/Library/Application Support/jp.samplebrowser/annotations.json` |
| 全体検索の索引・読み込み再開情報 | このMacの `~/Library/Application Support/jp.samplebrowser/library-index.sqlite3` |
| 自動試聴のON／OFF | このMacのアプリ設定（UserDefaults） |
| 加工WAV | `~/Music/Sample Browser Exports/` |
| 共有APIの端末資格情報 | macOSのKeychain |

お気に入り・メモ・タグ・全体検索の索引はMac内に保存し、原音へ書き込みません。サーバーの共有索引とは別管理で、Mac間の自動同期はありません。

旧名Sample Browserからのデータ互換性を保つため、`jp.samplebrowser` 系の内部識別子・保存先と `~/Music/Sample Browser Exports/` は維持しています。アプリ名・リポジトリ名の変更に伴うデータ移動は不要で、既存のお気に入り・設定・Keychain資格情報・DAWの参照先を引き継ぎます。

## 現在の制限

- BPM／キーの自動解析、DAWとの自動テンポ同期、出力機器の選択は未実装です。
- 波形ズーム、加工音声のリアルタイム処理、ギャップレスループ、加工キャッシュの容量制限と自動整理は未対応です。
- 加工はモノラル／ステレオが対象です。加工WAVは原音のサンプルレート・Float32形式で出力し、標準WAVの4 GBを超える出力は拒否します。
- Intel／macOS 14の実機試験、6 TB全量の性能試験、実素材の聴感品質、外部DAWへの実ドロップと保存後再オープンは未検証です。
- ソースからのビルドに対応しています。配布用の署名・公証済みアプリは提供していません。
